# Vascruz Import & Export SRL — Página web

Sitio oficial de Vascruz Import & Export SRL: importación de vehículos eléctricos de China a Bolivia.

- `index.html` — página principal (inicio, quiénes somos, proceso, catálogo, contacto)
- `img/` — logo y fotos de los vehículos

Publicado con GitHub Pages.

## Catálogo automático
- `catalogo.js` y `img/autos/` se generan desde el Excel de Vascruz con el botón **"Actualizar web"** de la Mac (carpeta *Cotizaciones vascruz*). No editarlos a mano.
- Solo contienen datos públicos (modelo, versión, año, colores, autonomía, precio de venta, ficha técnica y fotos). Nunca FOB, costos ni comisiones.
